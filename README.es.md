## 📂 Proyectos destacados

### 🗡️ [Lord of the Rings Blog](https://github.com/mjfy93/lotr-blog)
Enciclopedia moderna de LOTR con animaciones avanzadas
- Creada con React Router v7 (SSR), Vite y módulos CSS
- Integración segura de API utilizando rutas de recursos como proxies sin servidor para proteger los tokens de portador
- Animaciones WebGL avanzadas con React Bits y efectos de rayos de luz personalizados
- Menú interactivo con animaciones direccionales impulsado por GSAP
- Diseño responsivo con carga diferida y división de código


### 🔖 [BooketList](https://github.com/mjfy93/booketlist)
Aplicación de biblioteca virtual Full-Stack | Líder de equipo
- Desarrollada con React, Python, Flask y PostgreSQL
- Incluye autenticación de usuarios, colecciones personales de libros y sistema de calificación de 1 a 5 estrellas
- Implementación de API RESTful con SQLAlchemy ORM para operaciones CRUD
- Implementada en Vercel (frontend) y Render (backend)
